# Lab notebook

One dated entry per experiment or working session. Each entry pins a **run-id**
and a **git SHA** so that any number can be traced back to the code that produced
it.

Filename: `YYYY-MM-DD-short-slug.md`

An entry should say what you expected, what happened, and what you concluded —
especially when those three disagree. Negative results belong here; they are the
cheapest thing to lose and often the most expensive to rediscover.

When an entry produces a decision that constrains future work, promote it to an
ADR in `docs/decisions/`.
